# Event Assistant — демонстраційний застосунок

Україномовний вебпомічник для організації навчань, конференцій і зустрічей.

## Можливості демо
- Захищений кабінет організатора з панеллю статистики.
- 36 вигаданих учасників у шести демонстраційних компаніях.
- Додавання контактів та імпорт з Excel (.xlsx) або CSV.
- Створення заходу та вибір учасників.
- Імітація розсилки, індивідуальні посилання для відповіді.
- Миттєве відображення статусів «Підтвердив / Відмовився / Очікуємо».
- Імітація нагадувань; журнал дій; експорт звіту Excel і CSV.

**Демо не відправляє справжніх листів і не запускає планові нагадування.** Це наступний етап після підключення перевіреного домену пошти й зовнішнього планувальника.

## Локальний запуск

1. Створити Python virtualenv.
2. Встановити залежності: pip install -r requirements.txt
3. Установити ADMIN_PASSWORD (обов'язково) та SECRET_KEY.
4. Запустити python app.py.
5. Відкрити http://localhost:5000.

Для локальної перевірки дані зберігаються за замовчуванням у SQLite /tmp/event_assistant_demo.sqlite3.

## Render

Новий окремий Web Service, Python, build command: pip install -r requirements.txt,
start command: gunicorn app:app, health check: /health, region: Frankfurt.

Environment:
- ADMIN_PASSWORD — сильний пароль для входу (required).
- SECRET_KEY — випадковий довгий секрет (required for stable sessions).
- COOKIE_SECURE=1.
- DATABASE_URL — PostgreSQL URI (optional; recommended for persistent data).
- SQLITE_URL — SQLite URI (optional, for local or disposable demo).

Якщо DATABASE_URL не заданий, використовується тимчасовий SQLite. На безкоштовному Render файлову систему не можна вважати надійним постійним сховищем. **Не додавайте реальні контакти, доки не підключено постійну БД та не узгоджено обробку персональних даних.**

## Ізоляція

Код тимчасово розміщений в окремій Git-гілці для швидкої демонстрації; основна гілка та чинні сервіси AgroERP не змінювалися. Після створення нового репозиторію Event Assistant код можна перенести в нього без залежностей від AgroERP.
