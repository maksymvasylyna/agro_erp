# Підблок «Сівозміна» — AgroERP

URL: `/structure/rotation` («Структура посівних площ» → «Сівозміна»).

## Призначення

Повністю read-only звіт на основі довідника `Поля`:
`fields` → `field_seasons` → `field_plantings` + `seasons`,
`clusters`, `companies`, `cultures`.
Відтворено логіку аркуша `Історія полів` з корінного документа:
один рядок для поля, роки в хронологічному порядку, **дві колонки
«Площа, га» і «Культура» для кожного року**.

Цей звіт не залежить від глобального селектора поточного сезону.
Відображає всі роки, які є в `seasons` (наразі 2020–2027); при додаванні
нового сезону колонка з'являється автоматично.

## Фільтри

- Роки від–до — керують відображеними колонками (не новими записами).
- Кластери → підприємства → умовні масиви → культури — багатозначні
  фільтри, каскадний вибір, пошук у списках, «Вибрати всі»,
  «Зняти всі», автоматичне застосування без кнопки.
- Рік культури: культура шукається в певному році, або в будь-якому
  із показаних років. **Інші роки відібраного поля залишаються видимими.**
- Пошук за номером поля.
- Площа від/до: **один і той самий сезон** поля має потрапити в межі
  діапазону; річна площа включає все фізичне поле.
- Перегляд за полями / за умовними масивами; в останньому варіанті
  показується сума площ полів і розподіл культур за кожний рік.
- Сторінки по 50/100/250 рядків; підсумки під таблицею завжди для
  **повної відфільтрованої вибірки**, не лише поточної сторінки.
- CSV (UTF-8 з BOM) для Excel: всі рядки поточної відфільтрованої
  вибірки, включаючи ті, що на інших сторінках.

## Значення «масив»

Окремого довідника фізичних масивів наразі немає. Для попереднього
групування застосовується префікс у номері поля (`АКПР 091` → `АКПР`).
Група додатково розділяється за підприємством та кластером.
Це **не картографічні межі масивів**; після додавання справжнього
довідника можна замінити цю похідну ознаку.

## Важливі нюанси

- Рік без `FieldSeason` відображає «—»; поле з кількома культурами
  в сезоні відображає їх окремо, із площею кожної культури.
- Архівні поля з сезонними даними **залишаються у звіті історії**.
- Старі поля без жодного сезонного запису не додаються до цього
  звіту як порожні рядки.
- Для історичних даних "Соняшник сторонній" примітка із довідника
  залишається доступною в підказці.
- Усі маршрути — тільки GET. Не виконується жодних операцій
  створення, оновлення чи видалення даних.
- Два попередні модулі структури посівних площ залишаються без змін.

## Продуктивність

Під час одного GET звіт завантажує сезонні поля та пов’язані посіви
із eager-loading, без N+1 SQL запитів. Фасети обраховуються із
спільного набору, таблиця рендерить одну сторінку, а інтерактивний
JavaScript оновлює лише результат. В експорті CSV використовується
та ж серверна логіка фільтрації, але без обрізання сторінок.
